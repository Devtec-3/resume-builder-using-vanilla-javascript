
 # Resume Builder with Vanilla JavaScript

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A simple, client-side web application that allows users to dynamically create, preview, and download a professional resume. This project is built entirely with **Vanilla JavaScript**, **HTML5**, and **CSS3**, demonstrating core web development skills without relying on external frameworks or libraries.

## ✨ Features

* **Dynamic Form:** Add, edit, and remove sections for work experience, education, and skills.
* **Real-Time Preview:** See your resume update live as you type.
* **Responsive Design:** Looks and works great on both desktop and mobile devices.
* **Print-Friendly:** A "Download" or "Print" button that uses the browser's print functionality to save the resume as a PDF.
* **No Dependencies:** Built with 100% Vanilla JavaScript, HTML, and CSS. No libraries or frameworks needed.

---

## 🛠️ Tech Stack

* **HTML5:** For the structure and content of the application.
* **CSS3:** For all styling, layout (using Flexbox/Grid), and responsiveness.
* **Vanilla JavaScript (ES6+):** For all interactivity, DOM manipulation, and application logic.

## Usage

1.  Fill out the form with your personal details, work experience, education, and skills.
2.  Use the "Add" and "Remove" buttons to manage multiple entries (like different jobs or degrees).
3.  Watch the resume preview on the side update instantly.
4.  When you are finished, click the "Print" or "Download" button to save your resume using your browser's "Save as PDF" feature.
